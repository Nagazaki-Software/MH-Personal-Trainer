---

## 📱 Funcionalidades

- 📆 **Agendamento de treinos** com calendário integrado  
- 🧠 **Planos personalizados** com inteligência artificial (Gemini)  
- 🎥 **Aulas em vídeo** hospedadas via Mux  
- 📊 **Dashboard de progresso** para alunos e treinadores  
- 💬 **Chat entre aluno e treinador**  
- 💳 **Sistema de assinatura** com Stripe  
- 🔐 **Login seguro** com Firebase Auth  
- ☁️ **Backup e sincronização automática**
